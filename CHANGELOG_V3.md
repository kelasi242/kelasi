# KELASI v3.1.0 — Refonte UI

- Nouvelle interface mobile-first inspirée de l’application initiale : hero d’épargne, cartes arrondies, navigation native et sidebar responsive.
- Identité emerald/orange cohérente, thème clair/sombre, logo SVG et icônes PWA 180/192/512 + maskable.
- Dashboard enrichi avec progression, suivi BPC et échéance mensuelle, sans modification du modèle Supabase.

- Tableau de bord enrichi : total épargné, prévision novembre 2026 → novembre 2028, progression des projets et échéances.
